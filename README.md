# 教室座位表

一个可直接部署到 GitHub Pages 的静态教室座位表工具。页面默认不包含真实学生姓名，首次使用需要导入名单；“示例名单”只使用张三、李四、王五等虚拟姓名，便于演示。

## 功能

- 导入学生名单并随机或按顺序分配座位
- 点击两次座位交换学生，双击座位修改姓名
- Ctrl/Command 点击切换座位正常、锁定、禁用状态
- 排轮换、列轮换、第9列互换、增删排
- 本机自动保存、JSON 备份与恢复
- 生成座位表图片，支持安装为 PWA

## 直接使用

浏览器打开 https://zceason1.github.io/Classroom-Seating 即可立即使用
