# 教室座位表

一个可直接部署到 GitHub Pages 的静态教室座位表工具。页面默认不包含真实学生姓名，首次使用需要导入名单；“示例名单”只使用张三、李四、王五等虚拟姓名，便于演示。

## 功能

- 导入学生名单并随机或按顺序分配座位
- 点击两次座位交换学生，双击座位修改姓名
- Ctrl/Command 点击切换座位正常、锁定、禁用状态
- 排轮换、列轮换、第9列互换、增删排
- 本机自动保存、JSON 备份与恢复
- 生成座位表图片，支持安装为 PWA

## 部署

仓库使用静态文件，无需服务器和付费服务。上传到 GitHub 后，在仓库 `Settings -> Pages` 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root` 即可。
